**##Task1_StudentGradeTracker**
A Java-based application that allows teachers to input students' grades
CodeAlpha Task 1 - Student Grade Tracker

## Description:
This project is part of the Java Development Internship at CodeAlpha. It allows teachers to input student grades and calculate average, highest, and lowest scores.

## How to Run:

- Compile and run
